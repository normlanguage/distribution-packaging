# ThreeTen Backport for Fedora

Build the [spec](threetenbp.spec) with the upstream archives recorded in [source.json](../source.json). The time zone source follows the upstream release's Global-TZ rearguard version. The precompiled database is removed and regenerated by the upstream compiler during the Maven lifecycle, before tests run.

The [locale patch](jdk25-portuguese-weekdays.patch) updates seven Brazilian Portuguese weekday abbreviations to JDK 25 locale data. It retains every assertion. The package uses TestNG's standard result reporting in place of the upstream legacy listener configuration. Maven's functional tests run during `%build`; the optional duplicate artifact without time zone data is not installed.

Fedora 44 and isolated Fedora Rawhide mock builds: 17,869 tests passed in each build, zero failures, errors or skips. The [installed-package check](../tests/ThreeTenRoundTrip.java) verifies a daylight-saving transition, zoned date round trip and invalid date rejection.

Known Fedora 44 rpmlint findings: generated JDK Javadoc legal text contains an old FSF address; documentation size and the lack of a separate `%check` section produce warnings. Maven runs the upstream tests during `%build`.
